## Skills

Agent Skills from [anthropics/skills](https://github.com/anthropics/skills.git) are vendored under `.claude/skills/` so Claude Code picks them up automatically in this repository. Most skills are Apache 2.0; the `docx`, `pdf`, `pptx`, and `xlsx` document skills are source-available (see `.claude/skills/THIRD_PARTY_NOTICES.md`). To update, re-sync the `skills/` directory from the upstream repo.
